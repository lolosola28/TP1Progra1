# TP1-Programación-I

Trabajo práctico N1 - C2 Programación I: "A la mesa"

- Sistema de reservas de restaurantes

**Problemática que resolverá:** 
  El sistema propone un modelo de reservas para realizar modificaciones a reservas en restaurantes de manera online, brindando comodidad y sencillez para poder acceder a un comida gourmet de manera eficaz.

**Objetivo del sistema:**
  El objetivo de “A la mesa” es brindar a los restaurantes un sistema centralizado de reservas y organización de sus mesas, accesible y cómodo para sus comensales.

**Alcance del sistema:** 

  El usuario seleccionará:
  
  - El tipo de mesa que requiere (chica - mediana - grande) y tamaño de grupo.
  - Horario y turno de su reserva


  Y luego recibira una "facutra", indicando, su nombre, dni, tamaño de mesa, turno y horario de reserva y el número de su mesa indicada.
**Funcionalidades principale:** 
Registrar y guardar las reservas hechas por clientes para una mejor administración del uso de las mesas en el local.
